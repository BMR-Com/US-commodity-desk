One key, both complexes

EIA fundamentals, CFTC positioning and Open-Meteo weather, all client-side. Nothing is fetched from a server you have to run.
  1. Free key at eia.gov/opendata/register.php, paste it above, press Refresh all.
  2. It must be served over http. GitHub Pages does that; opening the file directly blocks every API call.
  3. Every refresh re-pulls all three sources and re-runs the models. The Desk tab rebuilds itself from whatever loaded.

Signal scorecardmechanical read across fundamentals, weather, valuation, positioning and curve

Press Refresh all. The scorecard needs storage, prices and COT at minimum; the weather model and fair value add two more components each and are fitted automatically where the data allows.
This is a rules engine over your own data, not a recommendation. Every component is shown with its raw input so you can see what is driving the score and override it. Positioning is treated as contrarian only at percentile extremes and ignored in the middle of its range.

Technical picture

EIA publishes settlement and spot closes, not open-high-low-close, so there are no candles and no true ATR. RSI, MACD and Bollinger are close-based by definition; the stochastic uses rolling close extremes rather than intraday highs and lows and will read slightly differently from a platform that has tick data.

Indicator summary

The technical score averages the directional indicators only — band width, ATR and realized volatility appear because they matter for sizing, but carry no direction. The score feeds the Desk tab as a momentum component.

Price source who your browser can actually reach

Press Load.
Prices and option chains come from GitHub Actions. There is no browser build of yfinance — the library is Python, and a page cannot read Yahoo's response at all because Yahoo sends no CORS header. The workflow runs fetch_data.py on a GitHub runner, which is a server and has no such restriction, and commits data/prices.json and data/options.json. Pages serves those alongside this file, so the page reads them same-origin and CORS never enters into it.

It runs on weekdays after the US settle. To refresh on demand, open the repo Actions tab, pick Refresh market data, and press Run workflow. Give it a minute, then reload this page.
Alpha Vantage is the one price API that does send CORS headers, so it works from a hosted page with no local step. Free key, ETFs only, small daily call budget.
